Practical 5: Raspberry Pi GPS Module Interfacing
Method 2: Manual UART Configuration

GPS Module Connections:

VCC  -> Raspberry Pi Physical Pin 2 (5V)
GND  -> Raspberry Pi Physical Pin 6 (GND)
TX   -> Raspberry Pi Physical Pin 10 (GPIO15 / RXD)
RX   -> Raspberry Pi Physical Pin 8 (GPIO14 / TXD)

Serial Port: /dev/ttyAMA0
Baud Rate: 9600


Step 1: Open the configuration file

sudo nano /boot/config.txt


Step 2: Add the following lines

dtparam=spi=on
dtoverlay=pi3-disable-bt
core_freq=250
enable_uart=1
force_turbo=1


Step 3: Save the file

Ctrl + O
Enter
Ctrl + X


Step 4: Stop the serial login service

sudo systemctl stop serial-getty@ttyS0.service


Step 5: Disable the serial login service

sudo systemctl disable serial-getty@ttyS0.service


Step 6: Enable the serial service

sudo systemctl enable serial-getty@ttyAMA0.service


Step 7: Reboot Raspberry Pi

sudo reboot


Step 8: Install required packages

sudo apt update

sudo apt install python3-serial

pip3 install pynmea2


Step 9: Optional Minicom installation

sudo apt install minicom


Step 10: Test GPS

minicom -D /dev/ttyAMA0 -b 9600


GPS should send data such as:

$GPGGA,...
$GPRMC,...
$GPGSA,...


Step 11: Create Python file

nano practical_5_gps.py


Step 12: Run the program

python3 practical_5_gps.py

import time
import serial
import string
import pynmea2
import RPi.GPIO as gpio

gpio.setmode(gpio.BCM)

port = "/dev/ttyAMA0"

ser = serial.Serial(
    port,
    baudrate=9600,
    timeout=0.5
)

while True:
    try:
        data = ser.readline()
    except:
        print("loading")

    if data[0:6] == b'$GPGGA':
        msg = pynmea2.parse(data.decode(errors="ignore"))
        print(msg)
        time.sleep(2)
